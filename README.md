# GTA V Add-On Installer

Windows-программа для пакетной установки add-on DLC-машин GTA V из ZIP/RAR-архива или папки.

## Поддерживаемая версия GTA V

Текущий режим OIV/OpenIV рассчитан на **GTA V Legacy** (в корневой папке должен находиться `GTA5.exe`). Если выбранная папка содержит `GTA5_Enhanced.exe` вместо `GTA5.exe`, установщик остановится до любых изменений. Для Enhanced нужен другой способ работы с игровыми архивами.

## Главное правило безопасности

**Программа направляет все изменения игровых файлов только в папку `GTA V\mods`.**

- DLC устанавливаются в `mods\update\x64\dlcpacks\<имя>`.
- Для регистрации DLC используется OpenIV OIV-пакет с путём `update\update.rpf` относительно корня игры. В OpenIV обязательно включается `Use mods Folder`: OpenIV сам направляет эту операцию в `mods\update\update.rpf`.
- Если `mods\update\update.rpf` ещё нет, программа только копирует туда оригинальный `update\update.rpf`. Оригинал не изменяется.
- Резервная копия `update.rpf` создаётся рядом с ним, внутри `mods\update`.
- Перед запуском OIV-пакета программа проверяет разрешённые относительные пути DLC и `update.rpf`. Важно: в OpenIV обязательно оставить включённой опцию `Use mods Folder`; без неё OpenIV может изменить оригинальные файлы.

Программа не редактирует `GTA V\update\update.rpf`, оригинальные игровые папки или другие файлы за пределами `mods`. Временный файл OIV-пакета создаётся отдельно в папке временных файлов Windows.

## Какой архив понимает программа

Можно передать сразу архив с несколькими машинами:

```text
cars.zip (или cars.rar)
└── Cars/
    ├── BMW_M5/
    │   └── dlc.rpf
    ├── Audi_RS6/
    │   └── dlc.rpf
    └── Mercedes_AMG/
        └── dlc.rpf
```

Программа найдёт **каждый файл `dlc.rpf`** и будет считать DLC-папкой ту папку, в которой этот файл лежит. Имя этой папки станет именем DLC. Для одного DLC можно вручную указать имя. Для архива с несколькими DLC оставьте поле имени пустым.

Если в архиве обнаружатся совпадающие имена DLC или хотя бы одна целевая папка уже существует, программа остановит подготовку пакета и ничего не перезапишет.

## Как проходит установка

1. Закройте GTA V.
2. Перетащите ZIP/RAR-архив или папку DLC в окно программы.
3. Выберите корневую папку GTA V — папку, в которой находится `GTA5.exe`.
4. Нажмите «УСТАНОВИТЬ DLC».
5. Программа подготовит OIV-пакет со всеми DLC и записями для `dlclist.xml`, затем попросит Windows открыть файл через приложение, связанное с расширением `.oiv`.
6. Если открылось только главное окно OpenIV, вручную выберите **Tools → Package Installer** и укажите файл `.oiv` из пути, показанного в сообщении программы. Запуск OpenIV сам по себе ещё не означает, что пакет загружен.
7. Убедитесь, что в OpenIV выбрана та же папка GTA V Legacy. Оставьте включённой опцию **Use mods Folder**. Когда установщик запросит папку назначения, выберите **Game folder / корень игры** — пути внутри пакета относительные к корню игры, а OpenIV должен направить изменения в `mods`.
8. Проверьте сводку операций в Package Installer и только после этого нажмите **Install / Установить**.

Вручную извлекать `dlclist.xml` и импортировать его обратно не нужно. Программа создаёт OIV-пакет формата 2.2, который применяет OpenIV; бинарный RPF-контейнер программа самостоятельно не переписывает. Временный `.oiv`-пакет создаётся в системной временной папке Windows; полный путь к нему показывается в сообщении программы.

## ZIP и RAR

- ZIP распаковывается встроенными средствами Python.
- Архив можно выбрать через «Обзор» или перетащить прямо в окно программы; также можно перетащить папку DLC.
- Для RAR должен быть установлен 7-Zip или WinRAR/UnRAR.
- Поддерживаются архивы с несколькими уровнями вложенных папок: программа сканирует источник и находит все папки, в которых лежит `dlc.rpf`.

## Запуск из исходников

Требуется Python 3.10+ и Windows с Tkinter. Для установки DLC и редактирования `dlclist.xml` должен быть установлен OpenIV.

```bash
pip install -r requirements.txt
python app.py
```

Для перетаскивания файлов используется пакет `tkinterdnd2` из `requirements.txt` (без него остаётся доступен выбор через «Обзор»). Для распаковки RAR требуется установленный 7-Zip или WinRAR.

## Сборка EXE

```bash
pip install -r requirements.txt pyinstaller
pyinstaller --onefile --windowed --collect-all tkinterdnd2 --name GTA5-Addon-Installer app.py
```

EXE появится в папке `dist`. OpenIV и (для RAR) 7-Zip/WinRAR устанавливаются отдельно.

Перед использованием рекомендуется сделать резервную копию папки `mods`.
