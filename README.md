# GTA V Add-On Installer

Windows-программа для установки add-on DLC-машин GTA V из ZIP/RAR-архива или папки.

## Какой архив понимает программа

Пример структуры архива:

```text
car_mod.zip (или car_mod.rar)
└── gt5/
    ├── dlc.rpf
    ├── content.xml
    └── setup2.xml
```

Имя DLC автоматически берётся из папки, в которой лежит `dlc.rpf`. В примере это `gt5`, поэтому программа создаст:

`GTA V/mods/update/x64/dlcpacks/gt5/`

и добавит в XML:

```xml
<Item>dlcpacks:/gt5/</Item>
```

Если внутри архива несколько файлов `dlc.rpf`, программа попросит оставить один DLC в архиве. При совпадении имени с уже установленной папкой программа не перезаписывает её, чтобы случайно не удалить другую машину.

## ZIP и RAR

- ZIP распаковывается встроенными средствами Python.
- Для RAR должен быть установлен 7-Zip или WinRAR/UnRAR. Программа использует их командную утилиту. Если утилита не найдена, программа покажет понятную ошибку.
- Поддерживаются файлы `dlc.rpf` в папке DLC, в том числе если внутри архива есть дополнительная корневая папка.

## Важно про dlclist.xml

Файл `dlclist.xml` находится внутри RPF-контейнера:

`mods/update/update.rpf/common/data/dlclist.xml`

В этой версии программа не редактирует `update.rpf` напрямую. Через OpenIV откройте `mods/update/update.rpf`, извлеките `common/data/dlclist.xml` во временную папку и выберите этот XML в программе. После установки замените XML внутри `update.rpf` через OpenIV.

Перед установкой рекомендуется закрыть GTA V и сделать резервную копию папки `mods`.

## Запуск из исходников

Требуется Python 3.10+ и Windows с Tkinter.

```bash
python app.py
```

Внешние Python-пакеты не нужны. Для распаковки RAR требуется установленный 7-Zip или WinRAR.

## Сборка EXE

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name GTA5-Addon-Installer app.py
```

EXE появится в папке `dist`. Это начальная сборка: RAR-файлы по-прежнему требуют наличия 7-Zip или WinRAR в Windows.

## Установка

1. Закройте GTA V.
2. Выберите ZIP/RAR-архив или папку с DLC.
3. Выберите корневую папку GTA V.
4. В OpenIV извлеките `dlclist.xml` из `mods/update/update.rpf/common/data/`.
5. Выберите извлечённый XML.
6. Оставьте имя DLC пустым для автоматического определения по папке рядом с `dlc.rpf`, или введите своё.
7. Нажмите «УСТАНОВИТЬ МАШИНУ».
8. Если программа добавила запись, импортируйте обновлённый XML обратно в `update.rpf` через OpenIV.

Перед использованием рекомендуется сделать резервную копию папки `mods`.
