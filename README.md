# GTA V Add-On Installer

Windows-программа для установки add-on DLC-машин GTA V из ZIP/RAR-архива или папки.

## Какой архив понимает программа

Можно передать сразу архив с несколькими машинами:

```text
cars.zip (или cars.rar)
└── Cars/
    ├── BMW_M5/
    │   ├── dlc.rpf
    │   ├── content.xml
    │   └── setup2.xml
    ├── Audi_RS6/
    │   └── dlc.rpf
    └── Mercedes_AMG/
        └── dlc.rpf
```

Программа найдёт **каждый файл `dlc.rpf`** и будет считать DLC-папкой ту папку, в которой этот файл лежит. Имя этой папки станет именем DLC. В примере создадутся:

- `GTA V/mods/update/x64/dlcpacks/BMW_M5/`
- `GTA V/mods/update/x64/dlcpacks/Audi_RS6/`
- `GTA V/mods/update/x64/dlcpacks/Mercedes_AMG/`

В `dlclist.xml` будут добавлены соответствующие три строки:

```xml
<Item>dlcpacks:/BMW_M5/</Item>
<Item>dlcpacks:/Audi_RS6/</Item>
<Item>dlcpacks:/Mercedes_AMG/</Item>
```

Для одного DLC можно вручную указать имя в поле программы. Для архива с несколькими DLC оставьте поле имени пустым — тогда имена определятся из папок автоматически. Если в архиве обнаружатся совпадающие имена DLC или хотя бы одна папка назначения уже существует, программа отменит всю установку и ничего не перезапишет.

## ZIP и RAR

- ZIP распаковывается встроенными средствами Python.
- Архив можно выбрать через «Обзор» или перетащить прямо в окно программы; также можно перетащить папку DLC.
- Для RAR должен быть установлен 7-Zip или WinRAR/UnRAR. Программа использует их командную утилиту. Если утилита не найдена, программа покажет понятную ошибку.
- Поддерживаются архивы с несколькими уровнями вложенных папок: программа сканирует архив и находит все папки, в которых лежит `dlc.rpf`.

## Важно про dlclist.xml

Файл `dlclist.xml` находится внутри RPF-контейнера:

`mods/update/update.rpf/common/data/dlclist.xml`

В этой версии программа не редактирует `update.rpf` напрямую. Через OpenIV откройте `mods/update/update.rpf`, извлеките `common/data/dlclist.xml` во временную папку и выберите этот XML в программе. После установки замените XML внутри `update.rpf` через OpenIV.

Перед установкой рекомендуется закрыть GTA V и сделать резервную копию папки `mods`.

## Запуск из исходников

Требуется Python 3.10+ и Windows с Tkinter.

```bash
python app.py
```

Для перетаскивания файлов используется пакет `tkinterdnd2` из `requirements.txt` (без него остаётся доступен выбор через «Обзор»). Для распаковки RAR требуется установленный 7-Zip или WinRAR.

## Сборка EXE

```bash
pip install -r requirements.txt pyinstaller
pyinstaller --onefile --windowed --collect-all tkinterdnd2 --name GTA5-Addon-Installer app.py
```

EXE появится в папке `dist`. Это начальная сборка: RAR-файлы по-прежнему требуют наличия 7-Zip или WinRAR в Windows.

## Установка

1. Закройте GTA V.
2. Перетащите ZIP/RAR-архив или папку DLC в окно программы либо выберите через «Обзор».
3. Выберите корневую папку GTA V.
4. В OpenIV извлеките `dlclist.xml` из `mods/update/update.rpf/common/data/`.
5. Выберите извлечённый XML.
6. Для одного DLC можно оставить имя пустым для автоматического определения или ввести своё. Для нескольких DLC оставьте поле имени пустым.
7. Нажмите «УСТАНОВИТЬ DLC».
8. Программа установит все найденные DLC и добавит недостающие записи в XML. Импортируйте обновлённый XML обратно в `update.rpf` через OpenIV.

Перед использованием рекомендуется сделать резервную копию папки `mods`.
